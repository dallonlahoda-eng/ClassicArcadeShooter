# Classic Arcade Space Shooter Implementation Plan

## Approach
Build a canvas-based arcade shooter with three files: `index.html`, `style.css`, and `game.js`. The game will feature:
- A player ship at the bottom controlled by arrow keys (left/right movement) and spacebar (shoot lasers)
- Waves of alien enemies descending from the top in formation
- Collision detection between lasers/enemies and enemies/player
- Score tracking and lives system
- Game over / restart flow
- Retro pixel-art style using canvas drawing primitives

## Files to Create

### 1. `index.html`
- Basic HTML5 boilerplate
- Canvas element (480x640 — classic arcade aspect ratio)
- Links to `style.css` and `game.js`
- Title screen overlay divs for start/game over states

### 2. `style.css`
- Dark space-themed background (#0a0a1a or similar deep dark blue/black)
- Centered canvas layout with flexbox
- Retro arcade-style typography (using a monospace or pixel font via Google Fonts — "Press Start 2P")
- Styled overlay text for score display, start screen, game over screen

### 3. `game.js` — Full Game Logic
**Game States:** `START`, `PLAYING`, `GAME_OVER`

**Player (`Player` class):**
- Position at bottom center of canvas
- Drawn as a retro spaceship shape using canvas paths (triangle ship with wings)
- Moves left/right with ArrowLeft/ArrowRight keys
- Shoots lasers with Spacebar (with cooldown timer to prevent spam)
- Has 3 lives, invincibility frames on respawn

**Enemy (`Enemy` class):**
- Drawn as retro alien shapes (different colors for variety)
- Spawn in formation rows from the top
- Move downward with slight sine-wave horizontal drift for that classic feel
- Increase speed as remaining enemies decrease (classic pressure mechanic)

**Laser:**
- Simple upward-moving rectangle (bright green or cyan)
- Player lasers go up; enemy lasers occasionally fire down (for extra challenge)

**Collision Detection:**
- AABB (axis-aligned bounding box) collision for all objects
- Laser hits enemy → enemy destroyed, score + points, explosion particles
- Enemy hits player → lose a life, invincibility frames
- Enemy reaches bottom → game over if too many pass through

**Game Systems:**
- **Score:** Displayed top-left; enemies worth different points based on type
- **Lives:** Displayed top-right as small ship icons
- **Wave System:** Enemies spawn in waves that get progressively harder
- **Particles:** Simple explosion effect when enemies are destroyed (small squares flying outward)
- **Stars Background:** Scrolling starfield for atmosphere

**Game Loop:**
- `requestAnimationFrame` driven
- Fixed update step for consistent physics
- Separate render pass

## Risks & Complexity
- **Low risk, medium complexity.** All canvas-based, no external dependencies needed.
- The main challenge is making the game feel good (responsive controls, satisfying explosions, balanced difficulty).
- No build system required — just open `index.html` in a browser.

## Complexity: Medium
Single developer can complete this. Estimated scope: ~400-600 lines of JavaScript total across all files.
